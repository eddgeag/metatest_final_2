# Gráficos de presentación (solo lectura)

Crear aquí nuevos scripts R para visualizaciones, figuras de tesis, pósteres o presentaciones.
**No** ejecutar nuevos modelos, reseleccionar biomarcadores ni actualizar datos fuente.
Leer resultados congelados por `UPSTREAM_DIR` / `SELECTION_RUN`, y escribir salidas de
presentación en un directorio de resultados **externo al repositorio**, por ejemplo
`RESULTS_ROOT/plots_presentation`. Documentar el origen de cada figura, la versión
del commit y los parámetros gráficos.

Los scripts exploratorios existentes 19–22 siguen conservados en
`scripts/biomarker_selection/`; no se trasladan ni alteran aquí.
